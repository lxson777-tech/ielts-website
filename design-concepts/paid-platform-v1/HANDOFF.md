# Paid platform concept board v1

Status: unapproved first direction.

This folder contains one high resolution concept board showing three screen directions only: public homepage, student dashboard, and lesson view. The visual system uses graphite, ivory, and restrained electric citrus, with dark navigation framing, light reading surfaces, condensed headlines, and a signature metal accent.

The board is a visual reference for a future paid IELTS platform. Preserve the full product intent: all five skills, real lessons, quizzes, trainers, listening and reading tests, accounts, progress tracking, AI writing and speaking feedback, and live examiner access. Future implementation must remain accessible and responsive.

The image's copy and layout are representative, not the source of truth. Do not automatically copy incidental image slogans or stock photography. A later cloud implementer must read the real repository and use its actual content. No pricing or custom domain has been chosen. No code or deployment is part of this phase.

Generated with the built-in image generation tool using the final brief: “Graphite and warm ivory IELTS platform with restrained electric citrus, dark structural framing, light reading surface, condensed editorial headlines, technical rules, premium almost-futuristic calm; three connected screens for homepage, dashboard, and lesson; avoid purple gradients, generic AI styling, stock card grids, glassmorphism, and decorative glows; preserve authentic True / False / Not Given lesson content and Spam Messaging passage.”
## Brand name

The current approved platform brand name is **IELTS is EZ**. This v1 handoff and its image filenames remain historical concept assets.
