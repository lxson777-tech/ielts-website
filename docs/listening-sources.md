# Listening practice sources

The 30 full listening tests come from [PracticePTEOnline](https://practicepteonline.com/), one numbered source page per test. Alex confirmed permission from the publisher on 2026-09-11 to reuse these free materials on the IELTS Portal.

**Licence:** publisher permission confirmed by Alex on 2026-09-11 for reuse and on 2026-09-14 for paid access.

Tests 1 to 5, 7 to 14, 16 to 30 use the numbered URL pattern `https://practicepteonline.com/ielts-listening-test-N/`. Two older pages use different canonical addresses:

- [IELTS Listening Test 6](https://practicepteonline.com/ielts-listening-6/). The apparent `/ielts-listening-test-6/` address redirects to unrelated Test 60.
- [IELTS Listening Test 15](https://practicepteonline.com/listening-15/). The apparent `/ielts-listening-test-15/` address redirects to Test 151, which duplicates the earlier Test 5 material.

Before importing tests 21 to 30, every one of the ten numbered URLs was fetched fresh and its page `<title>`/H1 was checked to read "IELTS Listening Test N" for the intended N. None of the ten redirected elsewhere, so no `SOURCE_URLS` overrides were needed for this range.

The importer is `tools/import_listening.py`. It keeps source HTML in `.tmp/listening-source` for review, downloads each complete MP3, copies original map and diagram images locally, and generates 40 sequential question records per test. The question paper keeps the published instructions, word limits, tables, notes, options, flow charts, and diagrams. Answer entry forms, answer panels, scripts, buttons, and advertising markup are removed. Run it as `python tools/import_listening.py [start end]`; with no arguments it imports the original tests 1-20, and `python tools/import_listening.py 21 30` imports just that range without touching or re-downloading anything outside it.

Unordered two and three answer groups share an `answerPairId`, so the learner can enter the accepted answers in any order without earning duplicate marks. Test 16 is a documented source exception: questions 11 to 14 each request two choices under one question number, and its answer key sits in a visible paragraph after the Show Answers control instead of the usual hidden answer panel. Those four questions use per-question unordered multi-select scoring and still count as questions 11 to 14, one mark each. Question 14 choice E contains the publisher's wording “available for from midday”; it is retained exactly rather than silently edited.

Test 11 has one publisher omission. Its Part 2 question paper contains questions 11, 12 and 13, then jumps directly to the Questions 15-20 heading. Question 14 appears only in the answer key, so its wording and options cannot be recovered from the authorized source. The site keeps number 14 visible to preserve the original 1-40 sequence, labels it unavailable, and excludes it from scoring. Test 11 therefore has 40 numbered slots and 39 scored questions.

Per-part audio timing and transcripts come from local speech-to-text (faster-whisper base.en), not the publisher. `tools/apply_listening_transcripts.py <transcript_dir>` reads each `test-NNN.json` transcript (segments plus detected part-start times) and stamps `startSeconds`, `endSeconds`, and a paragraphed, timestamped `transcriptHtml` onto each part's stimulus in `listening-full-NNN.ts`. It never touches question or answer data, and is safe to re-run. Since it is machine transcribed, it can misspell names, mishear numbers, or render a spoken range like "5 to 12" instead of the answer key's "5-12"; the transcript is shown to students as a study aid only, marked as automatic and possibly imperfect, with the answer key remaining authoritative.

## Corrections to the publisher key

Teachers writing the review explanations occasionally find a plain typo in the publisher's answer key, confirmed against the transcript. Two are recorded so far, both in `ANSWER_OVERRIDES` in `tools/import_listening.py` (mirroring the reading importer's table of the same name), so a re-import keeps the fix instead of reintroducing the typo:

- **Test 9, question 1**: the published key read "busines". The transcript has the student say "I'm doing a degree in business studies", so the answer is stored as "business" and the misspelling is not taught.
- **Test 20, question 38**: the published key read "grandads old air", misspelling ale as air. The transcript has the lecturer say "a beer they called Grand Dads Old Ale", so the answer accepts both "Grandad's Old Ale" and "grandads old ale" (the scorer's `normalizeAnswer` only strips a leading or trailing quote mark, not an apostrophe in the middle of a word, so both spellings are listed explicitly).

## Tests 21-30

Tests 27 and 30 use per-question two-answer multi-select the same way Test 16 does (`PER_QUESTION_MULTI` in the importer, now keyed by test number so more than one test can use it): Test 27 questions 8 and 9 each ask for two letters from a seven-option list, and Test 30 question 6 asks for two letters from a four-option list. Tests 27 and 30 also introduced the first multiple-choice groups in this set with more than three options (Test 27 questions 1-3 use A-D, Test 30 questions 31-40 use A-D); the importer's option list is now configurable per group (`MC_OPTIONS`) instead of always assuming three.

Three source quirks in this range needed a fix or a note, the same way tests 6, 11, 15, and 16 did:

- **Test 25, question 25.** Every question in its Section 3 note list is numbered like "24. place names describing geographic features", except question 25, which the publisher printed as "25 influence of immigration on place names" with no period. That dropped its answer blank onto question 24 instead. Fixed with a single exact-text substitution in the importer (`SOURCE_TEXT_FIXES`), applied only to test 25's own fetched HTML before parsing, so it cannot affect any other test's numbering.
- **Test 28, Part 1 heading.** The source heading reads "Part 1: Questions 1 and 2", but the form beneath it actually numbers its blanks (1) through (10), and Part 2 picks up at question 11 with no second heading in between. The heading text is a publisher typo; the site's own group metadata spans the true 1-10 range, so the mislabeled heading has no effect on scoring or layout.
- **Test 30, question 6.** The source presents this as a checkbox question with four options, but options B and C were not the Latin letters they look like: the publisher's raw markup has Cyrillic В (U+0412) and С (U+0421) in their place, most likely pasted from a Cyrillic-locale editor at some point. They render identically to Latin B and C, so this was invisible without reading the raw HTML. The importer now restores an option marker that isn't a plain Latin A-Z (`repair_corrupted_option_letters`): a Cyrillic homoglyph maps straight to its correct Latin letter, and the rarer case of an outright lost character (a genuine replacement character) is only inferred when the surviving letters in the same option list confirm a consecutive A, B, C... sequence at that position. This is a general repair, not specific to test 30, and it changed nothing for tests 1-20 (confirmed by re-generating them and diffing against the versions already on `main`).

**Duplicate found and kept, flagged for a decision.** Test 24's Section 2 (questions 11-20, the "Refreshments will be served" / "Nick Noble" community-club passage) is a near-verbatim duplicate of Test 18's Section 2, with the same 10 questions in the same order and only trivial wording differences ("advertised" vs "advertise", "reasonable fit" vs "reasonably fit"). The other three sections of Test 24 (30 of its 40 questions) are original, unique content with their own audio. Rather than discard an otherwise-original test or silently ship a section a student may have already seen, it was imported in full and is flagged here: Alex may want to trim or replace questions 11-20 of Test 24 later. No other section-level match above roughly 50% word overlap between any of tests 21-30 and 1-20 held up under inspection; the rest were short sections whose overlap was just shared instruction boilerplate ("Write NO MORE THAN TWO WORDS for each answer"), not real content.

Audio for tests 21-30 totals 180.23 MB across the ten MP3s (roughly 16-22 MB each), copied into `public/audio/listening/test-021.mp3` through `test-030.mp3` the same way as the original 20. Diagram images for tests 23, 24, 28, and 29 were copied into `public/pics/listening/imported/` the same way as the earlier tests that have maps or plans.
