# Scroll score

Grammar: bespoke illustrated quest map. It keeps one character and route through distinct scenes. Continuous world lost because a full worldflight would prevent the requested four section structure. Filmic one-shot lost because there is no footage. Editorial, live surface, typographic poster, gallery, split stage and rhythmic cutlist all lost because the story is a spatial character journey.

| Beat | Device family | Why |
|---|---|---|
| Recognition | pin, kinetic type and layered parallax | The struggle and promise share one dimensional opening composition. |
| Route | flow, staged entrance and directional reveal | Clarity feels like the page releasing into a readable map. |
| Four encounters | horizontal pan with live disclosure controls | Sideways travel gives each skill a distinct physical opponent. |
| Breakthrough | bespoke sticky progress choreography | The character and crack respond directly to scroll at the emotional peak. |
| Finish | resolved flow composition | The selected target holds in a calm, celebratory destination. |

Signature move: a persistent route fills through the whole page while the chosen target band updates all finish-line destinations and persists for the dashboard.

Fingerprint gate: registry was empty, so this first build clears automatically.
