Matching Features

What is it?

The official name for this task is Matching Features. Some books and older material call it "classification" or "categorisation". On the paper the rubric names the feature directly. Academic Reading Test 5, Questions 23 to 26, for example, says "Look at the following statements and the list of people below. Match each statement with the correct person, A-E." You are given a list of statements and a set of options, usually people, theories, places, dates, or groups. You must decide which option each statement belongs to, based on information in the passage. Some options may not be used at all, and an option can be used more than once when the instructions say so.

Key Rules

  • Your answer is always a letter
  • Several questions can share the same letter, but only when the instructions say "You may use any option more than once"
  • Some of the options are never used
  • The options are usually people, theories, places, dates, or groups
  • Do not assume the answers run in passage order. The mentions can be scattered through the text
  • The passage decides which option. Use only what's in the text

How to Approach It

  1. Read the categories carefully, and understand what each one represents.
  2. Skim the passage to identify which section refers to each category.
  3. Read each statement and identify keywords.
  4. Locate the relevant passage section and decide which category the information belongs to.
  5. Don't panic if the same letter appears several times. That is normal, as long as the instructions allow it.
⚠ Trap: relying on general knowledge instead of the passage ⚠ Trap: assuming each category is used only once
