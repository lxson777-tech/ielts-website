Yes / No / Not Given

Yes / No / Not Given

What is it?

The official name for this task is Yes / No / Not Given. On the paper it reads something like: "Do the following statements agree with the claims of the writer in Reading Passage 3? Write YES if the statement agrees with the claims of the writer, NO if the statement contradicts the claims of the writer, NOT GIVEN if it is impossible to say what the writer thinks about this." Some versions ask about the views of the writer rather than the claims; they are the same task. You decide whether each statement matches, contradicts, or is absent from the writer's own opinions and claims.

How It Differs From True / False / Not Given

  • True / False / Not Given tests facts: things that are objectively so, whoever wrote them.
  • Yes / No / Not Given tests the writer's opinions and claims: what this particular author believes or argues.
  • Here, NOT GIVEN means the writer expresses no view on the statement at all, not that a fact is missing.
  • This task only appears with a passage that argues a point of view. Official material says at least one of the three passages contains a detailed logical argument, and this task is set on that kind of text, never on a purely factual one.
  • Write YES, NO or NOT GIVEN. Writing TRUE or FALSE on this task is marked wrong.

How to Approach It

  1. Underline words in the statement that show it is about an opinion, not a fact: "believes", "argues", "the real reason", "should".
  2. Scan for the matching part of the passage. Answers come in the same order as the passage.
  3. Check whose opinion is being reported. A view the writer only quotes from someone else (an "advocate" or a "critic") is not automatically the writer's own view.
  4. Compare the statement's strength to the writer's: an absolute claim ("always", "never") is NO if the writer only hints at something weaker.
  5. If the writer never states a view on the exact point in the statement, choose NOT GIVEN. Do not guess what they would probably think.
⚠ Trap: a strong opinion reported from someone else is mistaken for the writer's own ⚠ Trap: assuming NOT GIVEN means the writer disagrees, when really they simply never mention it ⚠ Trap: an idea the writer clearly believes is worded so differently in the statement that it looks unrelated
A statement can be factually true in the real world and still be the answer NO, if the writer of this particular passage argues against it. You are marking the writer's claims, not the real world.
